# 07 — Feature Suggestions (from market leaders)

Sources of inspiration: Asana, ClickUp, Monday.com, Trello, Jira, Linear, Notion, Todoist, Basecamp, Hubstaff/Time Doctor (monitoring), Slack. (Based on general product knowledge; re-verify specifics before copying any behavior.)

## Recommended for v1.x (high value, low effort)
| Feature | Inspired by | Why for Traxio |
|---|---|---|
| Command palette (⌘K) + global search | Linear, Notion | Fast navigation; feels premium |
| Task comments with @mentions + file attachments | Asana, ClickUp | Context stays on the task |
| Custom recurrence (weekdays, weekly, monthly) | Todoist, ClickUp | Beyond "every day" |
| Task templates & duplicate task | Monday, Asana | Speeds assignment |
| Saved views / filters | ClickUp, Jira | Admin shortcuts |
| Calendar view of tasks | Asana, ClickUp | Planning visibility |
| Employee workload view | Monday, ClickUp | Balance assignments across businesses |
| Attendance clock-in/out + shift timings | Hubstaff | Natural pair with presence/leave |
| Notification center preferences (per-type, quiet hours) | Slack | Reduce noise |
| Dark mode + theme accents | Linear | Already planned |
| Undo toasts + bulk actions | Gmail, Todoist | Efficiency |
| CSV/PDF export for reports | most | Owner reporting |

## Valuable next wave
- Time tracking per task (start/stop timer) and estimate vs actual — ClickUp/Harvest
- Daily end-of-day auto-report to admin (WhatsApp/email) — Basecamp "check-ins"
- Employee performance score + streaks/badges, "Employee of the week" — gamification (Todoist Karma)
- Manager role per business; multiple admins
- Task SLAs per priority (auto-escalate faster for High)
- Goals/OKRs linked to tasks — Asana/ClickUp
- Workflow automations builder ("when blocked → notify admin") — Monday/Asana rules
- Custom fields & tags per business — ClickUp
- Recurring task skip/reschedule with reason
- Email notifications & digest
- Urdu / RTL language support
- Client tag per task + client-wise reports
- Focus mode / Pomodoro for employees
- Voice-note attachments in questions/chat (useful on mobile)
- Public/read-only share link for a report
- Knowledge base / SOP pages attached to daily tasks — Notion
- AI helpers: auto-summarize journals daily, suggest priorities, draft reminder text, detect repeatedly-blocked tasks

## Deliberately NOT recommended
Screenshot capture, keystroke logging, webcam monitoring: legal/ethical risk, trust damage, and exceed the app's browser-only scope.
